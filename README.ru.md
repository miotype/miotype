Курсор может стоять в терминале, VS Code, Cursor, в промпте Claude Code или Codex, в ветке Slack или в сообщении коммита — MioType всё равно. Он печатает туда, где фокус.

## Сочетания клавиш

| Клавиши | Что происходит |
|---|---|
| <kbd>Fn</kbd> | Нажмите, чтобы начать говорить, и ещё раз, чтобы вставить текст. <kbd>Esc</kbd> отменяет |
| <kbd>Fn</kbd> + <kbd>Space</kbd> | Спросите что угодно. Выделите текст, чтобы спросить о нём, или скажите «сделай короче», чтобы переписать его на месте |
| <kbd>Fn</kbd> + <kbd>Left Shift</kbd> | Говорите на одном языке — получайте другой |
| <kbd>Fn</kbd> + <kbd>Control</kbd> | Перевести выделенное на ваш язык или на любой другой |
| <kbd>Fn</kbd> + <kbd>R</kbd> | Отредактировать выделенное на месте |
| <kbd>Fn</kbd> + <kbd>S</kbd> | Найти слово или выражение |

Все сочетания можно изменить в настройках.

## Почему это нравится разработчикам

- **Печатает там, где курсор.** Без отдельного окна и без копирования. Надиктуйте длинный промпт для ИИ-агента, описание PR или ответ в issue прямо на месте.
- **Смесь языков остаётся смесью.** Термины и имена, сказанные по-английски, остаются английскими, на каком бы языке ни была остальная фраза.
- **Запоминает вашу лексику.** Исправьте неверно распознанное слово сразу после диктовки (`kubectl`, `useEffect`, имя коллеги), и MioType добавит его в словарь — в следующий раз будет правильно. Словарь можно и импортировать.
- **Офлайн — одним переключателем.** Выберите в настройках локальную модель Whisper, и голос не покинет ваш Mac. Работает без сети и без аккаунта.
- **Свой ключ API.** Распознавание и редактирование можно направить к своему провайдеру API вместо MioType Cloud.

## Конфиденциальность

- Локальный Whisper работает полностью на вашем Mac.
- В облачном режиме аудио или текст каждого запроса проходит через наш сервер в Alibaba Cloud Model Studio, а результат сразу возвращается к вам. Наш сервер не хранит ни аудио, ни текст — только число слов, тип и время запроса, чтобы считать вашу квоту.
- Со своим ключом запросы идут с вашего Mac напрямую выбранному провайдеру.
- Мы не обучаем модели на ваших данных и не используем рекламу и трекеры.
- Полная политика (на английском): [miotype.com/privacy](https://miotype.com/privacy)

## Требования

- Mac с Apple silicon (M1 или новее)
- Доступ к микрофону и универсальному доступу. MioType попросит их при настройке
